Dependencies:
- ```numpy``` == 1.26.4
- ```pandas``` == 2.2.3
- ```dask``` == 2024.4.1
- ```xarray``` == 2025.4.0
- ```torch``` == 2.6.0+cu126
- ```matplotlib``` == 3.8.4

```sed.ipynb``` contains the code for the Spatiotemporal Decoder final architecture.

```mlp.ipynb``` contains the code for the baseline model MLP.

```flatn-rnn.ipynb``` contains the code for the baseline model RNN (LSTM).

```cnn_starter.ipynb``` is the provided started code.

```sed-ablations.ipynb``` contains the experiments for varying the number of convolutional layers.

```/plots``` directory contains all the plots used in the report.
